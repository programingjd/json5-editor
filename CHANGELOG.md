# Changelog

## Version 0.1.3

### Fixes

Keep the editor selection visible when it loses its focus to the search/replace input fields.

Dedicated mouse buttons for browser navigation now work correctly.

Merged upstream GPUI Kit fixes and improvements from 0.9.0 to 0.9.1

## Version 0.1.2

### Features

Double-click a word and drag before releasing the second click to extend the selection by whole words in either direction.

### Fixes

Merged upstream GPUI Kit fixes and improvements from 0.7.1 to 0.9.0

## Version 0.1.1

### Fixes

On Firefox-based browsers, key inputs stopped working after giving the focus to the search field.

Ctrl+F could still trigger the browser search rather than the editor search.

Right-padding on the search bar close button was missing.

Current line highlight didn't extend all the way to the right edge.
